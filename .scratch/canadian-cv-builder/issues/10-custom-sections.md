# 10: Custom sections

**What to build:** The user can add custom sections, each with a title and TipTap description. Each custom section is a **top-level** entry in the global section order (same level as Experiences / Education / Languages), not nested under a single “Custom” bucket. Save/Cancel/dirty guard apply per custom section.

**Blocked by:** 06 — Form pattern + TipTap + Header

**Status:** ready-for-agent

**Maps to:** US-09

- [ ] User can create multiple custom sections (title + description HTML)
- [ ] Each custom section appears as its own top-level section in the order model
- [ ] User can delete a custom section (with confirmation if destructive)
- [ ] Save/Cancel/dirty guard match the shared form pattern
- [ ] Preview renders each saved custom section with its title and HTML body
