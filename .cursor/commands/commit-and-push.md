description: Commit the current work and push the branch
---

Commit the current changes, then push this branch.

Look at status, diff, and recent commit messages first. Stage only the relevant files. Write a Conventional Commits message that says why. Do not amend, skip hooks, or force-push.

If there is nothing to commit, say so. Do not create an empty commit. If the commit fails, fix the problem and make a new commit. Then push.
